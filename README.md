# 純粹好食純淨優格快線

這是一個品牌向的可愛像素風橫版遊戲原型。玩家操作短髮、左手拿攪拌匙的優格師傅，在自動前進的純淨產線裡依序接原料、按設備、避開人工添加物，靠甜點區 PERFECT、連線倍率、純淨能量、精品出貨和純淨率衝高分。

品牌參考：<https://www.ugoodays.com/>

## 開啟方式

直接用本地靜態伺服器開啟：

```powershell
python -m http.server 4173
```

然後打開 `http://localhost:4173/`。

## 操作

- `上 / 下` 或 `W / S`：切換軌道
- `左 / 右` 或 `A / D`：微調位置
- `空白鍵 / E`：經過設備時按「做」
- 手機版沒有虛擬按鍵：上下滑動換軌，左右滑動微調位置，點一下畫面就是「做」

## 核心玩法

- 無限關卡：完成一批訂單後升關，前 4 關是建立手感的新手保護期，接著逐步解鎖純淨封杯線、益菌熟成線、口感研發線、精品爆單線與純淨極限線。
- 偶發硬局：少數開局會抽到 `快閃冷鏈局` 或 `黑標稽核局`，直接從中階壓力開始，秒數和純淨率更緊，讓每局有「這把很危險」的變化。
- 產線狀態：第 5 關後才開始抽冷鏈急單、精品加料等輕壓力狀態；純淨稽核、三軌快線、添加物警報會更晚解鎖，避免一開始就打掉信心。
- 品牌訂單：鮮奶優格、益菌優格、優格飲、希臘高蛋白優格、精品蜂蜜水果優格。
- 原料元素：鮮奶、益菌、高蛋白、鈣、水果、蜂蜜。
- 製程元素：混乳、低溫熟成、濾乳、純淨檢查、口感調整、封杯貼標、冷鏈出貨。
- 甜點區判定：接原料或按設備時越靠近主角前方甜點區，評價越高；`PERFECT` 會加秒數、加能量、加粒子回饋。
- 連線倍率：連續 `PERFECT` 會疊倍率，下一步會更快接上，形成「接準、變快、倍率更高」的循環。
- 營養道具：`純淨盾` 可擋下一次添加物，`益菌磁吸` 讓下一段目標更貼近玩家軌道，`鈣力慢拍` 會短暫放慢危險物。
- 連線獎勵：每 10 連線會爆一次額外分數、秒數和純淨能量；20 連線以上還會補純淨盾，鼓勵玩家追更長連線。
- 動畫回饋：PERFECT、營養道具、純淨盾擋下、連線獎勵、精品出貨與 PURE RUSH 都會觸發像素爆光、車道掃光或狀態光環；同車道危險物靠近時會出現短暫警示框。
- 安靜路過：錯過當前目標、碰到非目標原料、按到非當前設備都不計入任何操作，不跳失誤字樣，不扣分，不提示，物件會自然滑出畫面。
- 本批挑戰：每批訂單會依當前可完成內容隨機抽任務，並避開最近重複題型；目標包含不碰添加物、連續 PERFECT、原料/設備 PERFECT、吃營養道具、換軌完成、整批 GOOD 以上、純淨盾擋添加物、打出 PURE RUSH、長連線等。
- 純淨能量：照順序完成會加連擊、加純淨能量、加秒數；能量滿格進入 `PURE RUSH`，短時間高倍率得分。
- 精品出貨：一批訂單完全無失誤會給額外分數、純淨率與能量，鼓勵玩家不只求快，也要符合品牌的純淨製作調性。
- 死亡機制：前期主要練手感，後期倒數流失才會逐步變快；碰到人工香精、色素、髒汙、過糖會扣純淨率和秒數，且稽核/警報狀態會扣得更重；秒數或純淨率歸零就結算。
- 本地排行榜：目前用 `localStorage` 保存，之後可替換成後端排行榜。
