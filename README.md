# 純粹好食純淨優格快線

這是一個品牌向的可愛像素風優格收集遊戲原型。玩家操作短髮、左手拿攪拌匙的優格師傅，在臺南街景道路中滑動換線，主動吃到鮮奶、益菌與工序道具，避開紅色香精、色素、額外糖與添加物，合成純粹好食在售優格。

品牌參考：<https://www.ugoodays.com/>

## 開啟方式

直接用本地靜態伺服器開啟：

```powershell
python -m http.server 4173
```

然後打開 `http://localhost:4173/`。

## 操作

- `左 / 右` 或 `A / D`：往左 / 往右換一格
- `上 / W`：回到中路
- `下 / S`：回到中路
- `空白鍵 / E`：經過設備時按「做」
- 右上角 `音 / 靜`：切換背景音樂與操作音效
- 手機版沒有虛擬按鍵：左滑 / 右滑換一格，手指不需要停在畫面上。

## 核心玩法

- 優格快線：時間越久速度越快，紅色添加物會更密集，玩家要追好料、閃紅色、維持連吃。
- 偶發硬局：少數開局會抽到 `快閃冷鏈局` 或 `黑標稽核局`，直接從中階壓力開始，秒數和純淨率更緊，讓每局有「這把很危險」的變化。
- 產線狀態：第 5 關後才開始抽冷鏈急單、精品加料等輕壓力狀態；純淨稽核、三軌快線、添加物警報會更晚解鎖，避免一開始就打掉信心。
- 合成目標：優先提示店內在售的希臘優格 160g、原味優格飲、鮮奶優格 160g；特調口味只作為低分備選。
- 原料元素：鮮奶、益菌、高蛋白、鈣、水果、蜂蜜。
- 製程元素：混乳、低溫熟成、濾乳、純淨檢查、口感調整、封杯貼標、冷鏈出貨。
- 合成提示：資訊欄會提示目前最接近哪一杯優格、還缺哪些材料，不再要求玩家依照固定出餐順序操作。
- 品牌功能：鮮奶補純淨、益菌牽引目標、高蛋白加分、鈣力慢拍、水果加能量、蜂蜜加秒數；混乳、熟成、濾乳、品檢、口感、貼標、出貨也各自帶有品牌功能，完成不同元素會累積 `品牌熱度`。
- 連吃節奏：連續吃到好料與道具會加分、補純淨能量並推進 PURE RUSH，不需要額外點按判定。
- 爽感道具：`限時加速`、`優格磁場`、`純淨盾`、`安心護欄`、`道路清場`、`純淨波` 等會提供短時間爆發，但出現頻率不高。
- 連線獎勵：每 10 連線會爆一次額外分數、秒數和純淨能量；20 連線以上還會補純淨盾，鼓勵玩家追更長連線。
- 動畫回饋：營養道具、純淨盾擋下、連吃獎勵、優格合成與 PURE RUSH 都會觸發像素爆光、車道掃光或狀態光環；危險物靠近時會出現短暫警示框。
- 背景音樂：用 Web Audio 即時生成舒緩休閒的短循環 hook，不依賴外部音檔；關卡升高只會微幅加速，進入 PURE RUSH 時多一層清亮音色，維持可愛、乾淨、耐聽的品牌感。
- 安靜路過：錯過當前目標、碰到非目標原料、按到非當前設備都不計入任何操作，不跳失誤字樣，不扣分，不提示，物件會自然滑出畫面。
- 本局挑戰：目標包含不碰添加物、吃營養道具、換軌躲紅色、純淨盾擋添加物、打出 PURE RUSH、拉高長連吃等。
- 純淨能量：吃到好料與合成官方優格會加純淨能量；能量滿格進入 `PURE RUSH`，短時間高倍率得分。
- 優格合成：吃到足夠材料後會自動封杯，官方純粹優格不增重，連續吃滿一定量還會減重。
- 死亡機制：碰到人工香精、色素、增稠劑、額外糖等紅色負元素會扣純淨率並增加體重；純淨率歸零或體重到 70kg 就結算。
- 本地排行榜：目前用 `localStorage` 保存，之後可替換成後端排行榜。
